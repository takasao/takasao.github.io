WHY THIS TOOL

どんなときに、役立つか。

プロフィール、研究内容、発表などを公開 Web サイトとして整理する Jekyll ベースの発信拠点です。

入力するもの

  • 公開可能な研究・業績情報
  • Jekyll の設定とページ

得られるもの

  • 公開サイトのページ
  • 研究活動の案内

CAPABILITIES & BOUNDARIES

できることと、判断が必要なこと。

現在使える機能

  • Jekyll と al-folio のサイト構成
  • GitHub Actions の配信 workflow
  • 研究・発表情報の管理

使う前に知っておくこと

  • 公開 repo と公開サイトの内容に注意する
  • bootstrap の同期だけではサイトを公開しない
  • 具体的な build 方式と必要バージョンは既存 workflow と README を確認
IN THE WORKSPACE

ほかの道具と、どうつながるか。

  • Reference List Maker が公開済みの発表履歴を参照
  • 私的な ResearchTrail ノートとは公開範囲を分離

各ツールは独立した repo です。コードの取得と、私的データ・認証・生成物の同期は、それぞれの手順で行います。
